# Civilian and geometry provenance

The two civilian exports were generated locally from parameter files in phase5/phase54c-revision-20261113 using the preserved 3d-gen/MakeHuman exporter source. MakeHuman asset license: CC0 1.0; complete upstream notice is supplied as ASSETS_LICENSE.txt. Idle/walk motion derives from the upstream CMU motion collection; attribution retained below. No film footage, dialogue recordings or protected Bhairava/Groom assets were used.

Upstream source and asset policy: https://github.com/olatunde85/3d-gen . Motion source: Carnegie Mellon University Motion Capture Database, http://mocap.cs.cmu.edu/ . Upstream exporter code license is preserved in the generator evidence folder. Distribution must retain applicable exporter/asset notices; no endorsement implied.

Civilian geometry and embedded images were exported, limited to Idle/Walk animations, and packaged with shared external texture files. Original texture dimensions were retained. Raw and compact exports, parameter files and packaging scripts are preserved in the revision evidence folder.

Riverfront building/quay/shrine/market geometry was generated for this isolated prototype using build-block.mjs. Existing project stone textures and Draco decoder are reused. Existing riverfront context remains unchanged. This is an original game environment study, not a reproduction of movie footage.
