# Fluent Telugu reviewer instructions

This is a content-review package, not game code, a voice pack or proof of linguistic approval. All202 entries start PENDING. No audio or personal save data is included.

1. Review each exact source/context/slot template. Source locations/hashes identify the baseline. Do not silently edit source fields.
2. Supply Telugu in reviewer_proposed_telugu, English meanings/back-translations in reviewer_proposed_english, and reasons in reviewer_comments. Leave uncertain idioms pending; transliterated barks with no supplied meaning need actual fluent interpretation.
3. Preserve distinctions between recorded completion, unlock, availability, unbuilt content, briefing-seen flags and unknown history/rewards. Do not narrate missing chapters. Keep mission IDs, numeric data and code placeholders separate from proposed language.
4. The missing greeting is a gap, not an authored line. A proposed greeting requires separate approval before implementation.
5. Only an actual fluent human can mark a line APPROVED or REJECTED: record reviewer name, date and approval evidence. Approval applies only to that source/proposed wording and context/version. Partial review does not approve the whole sheet.
6. Linguistic approval does not grant recording rights. Original performer/source/contract and distribution permissions remain separate prerequisites. No actor imitation, copied movie recording, TTS or voice generation is authorized here.
7. Return the edited Markdown or JSON for review. There is no automatic game importer; no campaign or English fallback changes happen from editing these files.

Source responses are existing baseline content. The two unapproved catalogue recordings remain blocked and excluded from production; the package contains metadata only. Human fluency, audible playback and physical-device tests remain unverified.
