Kashi courtyard: original authored 3D environment for this project, generated by
phase5/phase52-menu-quality/build-kashi.py. Editable Blender source and build
statistics are retained beside that script. No protected character asset used
in this geometry or opened by the generator.

Sandstone PBR color/normal/roughness/AO maps, 1K:
https://polyhaven.com/a/old_sandstone_02
Sunset lighting/blurred background panorama, 1K:
https://polyhaven.com/a/venice_sunset
Both Poly Haven assets are CC0: https://polyhaven.com/license
Powered by Poly Haven. API metadata and download URLs are retained in
phase5/phase52-menu-quality/. The application loads only local asset files.
The background HDRI is lighting/atmosphere, not a photograph of Kashi.

Draco decoder files originate from the installed Three.js distribution's
examples/jsm/libs/draco/gltf, produced by Google Draco, Apache License 2.0.
The character remains the existing protected model, without file modification.
