## Shared mission and cinematic rules

- Sequential dependencies remain 90 → 91 → … → 99 → 100. No ID insertion, save reset or legacy unlock deletion.
- Reuse the Phase 7 cinematic director, live world/player, mission-specific title/objective UI and current entry/restart/replay framework. Do not load a separate unrelated cinematic world.
- Each introduction establishes its actual location, frames the rear player view, uses an appropriate front/side or weapon shot, reveals only characters/threats actually staged, then returns control. Memory scenes use explicit presentation boundaries so imagery does not imply present-day ability activation.
- Skip may end a cinematic beat safely; it must not fabricate an unperformed combat, exploration or protection objective. A genuinely completed or deliberately skipped authored story scene may satisfy its story beat only after cleanup/handoff. Asset-load error, mission exit or interrupted loading never counts as completion.
- Replays are presentation-only: no new rewards, completion flags or ability grants. Continue within a checkpoint resumes without compulsory rewatch; restarting launches the introduction again. Scene checkpoints must distinguish not-started, active and resolved states.
- All original dialogue remains to be authored/reviewed. These descriptions are not Telugu dialogue drafts, movie quotations or verified scene transcripts. Existing muted/volume/priority audio hooks remain optional; no movie clips or actor imitation.
- Use current enemy roles and bounded encounters where justified. No new named villain, invented character death, future-child outcome, ancient biography or Yaskin defeat.
