## Build
Use Node22.12 or newer compatible release and npm:
npm ci
npm run verify:publication
npm run lint
npm run build

The dist directory is the deployable static site. GitHub Actions builds on main and deploys it to GitHub Pages. Repository Settings > Pages must use GitHub Actions.
Relative build assets and base-aware Draco decoding support repository-path hosting.
